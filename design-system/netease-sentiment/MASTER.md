# MASTER — 网易云爬虫 · 评论情感分析（Streamlit）

> 项目：`E:\sprider_163music` · 产品：网易云音乐爬取 + 评论情感分析仪表盘
> **设计语言：「纸刊 · 乐评月刊」——浅色印刷系统（用户选定，取代此前深色 + 雾化玻璃迭代）**
> 概念：把数据做成一份印出来的"云村乐评月刊"。母题 = 米白纸面 / 墨字 / 印红(Riso 双色) / 细墨线 / 直角 / 黑胶唱片。

## 1. 设计令牌（`ui.py` 顶部 `:root` 与 `.streamlit/config.toml` 同步）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ny-paper` / `backgroundColor` | `#F4EFE4` | 米白纸面 |
| `--ny-sheet` / `secondaryBackgroundColor` | `#FDFBF4` | 卡片纸 |
| `--ny-well` | `#ECE4D2` | 表头 / code 底 |
| `--ny-text` / `textColor` | `#1A1612` | 墨字（AA） |
| `--ny-text-2` | `#5B5346` | 次级墨 |
| `--ny-text-3` | `#6E6452` | 弱化（脚注/caption，AA ≈5.1:1） |
| `--ny-brand` / `primaryColor` | `#E62B2B` | 印红（识别色；填充按钮白字 AA） |
| `--ny-brand-2` | `#C01E1E` | 印红 hover 深档 |
| `--ny-blue` | `#2E6FB7` | Riso 蓝（第二识别色） |
| `--ny-hairline` | `rgba(26,22,18,.18)` | 细墨线 |
| `--ny-mono` | Cascadia/JetBrains/Consolas | 编号/索引/等宽 |

**禁令：本语言无 光晕 / 玻璃 / 紫粉渐变 / 柔和圆角大投影。** 投影只能是「硬错位影」（`3px 3px 0`），呼应印刷落版误差。

## 2. 情感语义色（纸面上调墨，保证文字 ≥4.5:1 / 色块 ≥3:1）

| 中文 | 英文 | 值 |
|---|---|---|
| 正面 | positive | `#1B7A44` |
| 中性 | neutral | `#9A6B11` |
| 负面 | negative | `#C62828` |
| 未知 | unknown | `#8C8273` |

规则：印红是**版面语言**（刊头/色条/主按钮/图例标记），负面红是**数据**，同屏分场景；图例/表格始终伴随文字，不靠颜色单独传义。

## 3. 版式与排版

- 刊头（报头）：`.ny-hero` —— 大字黑体 900 + 红色关键词；**4px double 细线**收底（报头鼻祖线）；右上角 `repeating-radial-gradient` 同心圆 + 红芯 = **黑胶唱片**；`.ny-over` 等宽小字 `MUSIC REVIEW · …` 大间距。
- 章节小标题 `h3`：墨字 800 + 左侧 3px 印红栏标（杂志栏目标）。
- 等宽数字 + `tabular-nums` 用于表格/数值，像刊号索引。
- 字体：本地系统栈（不引 Google）；代码/编号走 `--ny-mono`。

## 4. 组件约定

- **按钮**：直角 `2px`、1px 墨框；默认纸面，hover **反白**（墨底纸字）。主 CTA：印红实底 + 墨框 + `3px 3px 0` 墨色硬错位影（按下位移 `1px`）。
- **KPI 数据块**（≤4 张）：`.kpi` —— 纸卡细墨框 + **左侧 5px 色条**（红/蓝/情感色）+ 墨色大数字 + 破折线脚注；hover 向左上微移、印红错位影加深。
- **输入**：纸白底 + 墨线，聚焦换印红 1px；无柔光外发光。
- **进度/状态**：印红实心进度；状态框纸白细框。
- **标签页**：印刷目录式——`tab-list` 底部 1px 墨线，选中项 = 墨字 900 + 3px 印红下划线，**无胶囊底**。
- **侧栏**：纸面 + 右侧细墨竖线；品牌标 = 印红方块（硬错位影）。含**会话级「情感引擎」切换**（radio：local/llm，仅改内存 cfg，不写 config.json；默认值读自配置）。
- 图标：内联 SVG（Lucide 描边）；不用 emoji 当功能图标（favicon 🎵 与正文枚举 ①② 除外）。

## 5. 图表（Altair · st.altair_chart theme="streamlit"）

- 情感色阶即 §2 四色；柱/扇区去描边（纸面天然分隔）；数值标签 `INK_LABEL = #1A1612`（墨色，位于纸底之上）。
- 平均得分条形 `≥0.5 → 绿 #1B7A44 / <0.5 → 红 #C62828`；情感得分直方图 = 绿；评论时间分布 = Riso 蓝 `#2E6FB7`。
- 每图保留 tooltip / 图例 / caption / 表格降级（charts 规则全满足）。

## 6. 词云

- `background_color=None, mode="RGBA"`（透明，融入纸面）。
- 印刷墨色 palette：红 `#C62828` / 蓝 `#2E6FB7` / 墨 `#1A1612` / 绿 `#1B7A44` / 褐 `#8A5A2B` / 琥珀 `#9A6B11` / 灰褐 `#6E6757`，按词哈希取色。

## 7. 反模式（勿做）

- ❌ 加回 光晕 / 玻璃 / 紫粉渐变 / `backdrop-filter` / 柔光大圆角——整套语言直接失效。
- ❌ 用暖白以外的底（保持纸感）或恢复深蓝黑底。
- ❌ 把印红当数据负面色塞进情感图例（负面数据固定 `#C62828`）。
- ❌ 用大圆角（>2px）、软阴影代替硬错位影。
- ❌ 页面引 Google Fonts；功能图标用 emoji。
